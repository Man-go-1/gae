# 🚀 1-Month Java Learning Plan

## Overview

This 4-week plan is designed for beginners who want to build strong Core
Java fundamentals within one month. Recommended study time: **2--3 hours
per day**

---

# 🟢 Week 1: Java Fundamentals

## Goal: Understand syntax & basic programming logic

### Day 1--2: Setup & Introduction

- Install JDK
- Install IDE (IntelliJ / Eclipse / VS Code)
- Write your first program (Hello World)
- Understand JVM, JRE, JDK
- Learn Java compilation process

### Day 3--4: Variables & Data Types

- Primitive data types
- Type casting
- Operators
- User input using Scanner

### Day 5--6: Control Statements

- if, else
- switch
- for loop
- while loop
- do-while

### Day 7: Practice Programs

- Number guessing game
- Calculator program
- Prime number checker

---

# 🟡 Week 2: Object-Oriented Programming (OOP)

## Goal: Master OOP Concepts

### Day 8--9: Classes & Objects

- Class structure
- Constructors
- Methods
- this keyword

### Day 10: Encapsulation

- Access modifiers
- Getters and Setters

### Day 11: Inheritance

- extends keyword
- Method overriding
- super keyword

### Day 12: Polymorphism

- Method overloading
- Runtime polymorphism

### Day 13: Abstraction

- Abstract classes
- Interfaces

### Day 14: Mini Project

- Student Management System OR
- Bank Account Simulation

---

# 🔵 Week 3: Advanced Java Concepts

## Goal: Learn real-world Java tools

### Day 15--16: Collections Framework

- ArrayList
- LinkedList
- HashMap
- HashSet
- Iterators

### Day 17: Exception Handling

- try, catch, finally
- throw & throws
- Custom exceptions

### Day 18: File Handling

- FileReader
- FileWriter
- BufferedReader

### Day 19--20: Multithreading

- Thread class
- Runnable interface
- Synchronization basics

### Day 21: Practice Project

- Console To-Do List App OR
- File-Based Notes Manager

---

# 🔴 Week 4: Real-World Application & Interview Prep

## Goal: Apply knowledge practically

### Day 22--23: Java 8 Features

- Lambda expressions
- Streams API
- Functional interfaces

### Day 24: JDBC Basics

- Database connectivity
- CRUD operations

### Day 25--26: Introduction to Spring Boot

- REST API basics
- Simple web application

### Day 27--28: Final Project

Choose one: - Expense Tracker - Library Management System - Simple REST
API

### Day 29--30: Revision + Interview Preparation
